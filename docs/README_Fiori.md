Fiori App Skeleton

Files moved here from src/sample/fiori for abapGit import clarity:
- manifest.json -> docs/fiori_manifest.json

Usage:
- This is a minimal manifest to help you bootstrap a Fiori Elements Object Page app. Replace dataSource entries with the actual destination or direct URL to the OData service in your environment.
- To create a full Fiori Elements app, use SAP Business Application Studio or SAP Web IDE and choose "List Report/Object Page" template pointing to the service ZRAP_DEMO_SRV.
